# GUILEO DESK — contrato da rota `/api/desk` (para quem constrói tela)

Toda chamada: `POST /api/desk` com `{ email, key, action, ... }`. Use **`chamarDesk(email, key, corpo)`** de `src/portal/deskApi.js` (devolve `{ http, d }`, nunca lança). Erro de negócio vem como `{ ok:false, reason }` — traduza com **`motivo(d, http)`** do mesmo arquivo. Chave errada → HTTP 401.

Dinheiro é SEMPRE em centavos inteiros. Datas são ISO com fuso. O fuso de exibição é o da UNIDADE (`location.tz`), via `quando()`, `paraUtc()`, `diaDe()`, `minutoDe()` de `deskApi.js`. Moeda: `dinheiro(cents, tz)`; ler o que a pessoa digita: `centavos("140,50")`.

## Regras de tela (valem para todas)
- Conta conectada **nunca** mostra amostra. Lendo = `SectionSkeleton`; falhou = aviso com "tentar de novo". Sem conexão (`!conectado`) = amostra **declarada** e ações bloqueadas com aviso.
- Textos nos 4 idiomas (en/pt/es/hi), em tabela local `T` + `tx()`. Nada em inglês numa tela em português.
- Visual: cimento quente da Central (`#161512`), classes `text-g-word`, `text-g-muted`, `text-g-green`, `border-white/10`, `bg-white/[0.04]`, `rounded-xl2`; componentes `Card`, `Drawer`, `SectionSkeleton` de `../pages/Portal.jsx`; `toast` de `../lib/portalApi.js`. Não mexa em tokens globais.
- Toda escrita confere `d?.ok === true` antes de dizer "pronto". Sem `ok`, diga o `motivo()`.
